# Sales Performance Dashboard & Analytics Project

## Overview
This project analyzes sales call performance using Excel, Power Query, and Power Pivot. The solution includes a data model, KPI dashboard, sales funnel analysis, conversion tracking, and executive reporting.

## Business Objectives
- Track Sales Performance
- Measure Sales Conversion Rate
- Analyze Call Activity
- Identify High Performing Services
- Provide Actionable Business Insights

## Tools Used
- Excel
- Power Query
- Power Pivot
- DAX
- Pivot Tables
- Data Modeling
- Data Visualization

## KPIs
- Total Sales: 3.84M
- Total Calls: 3,508
- Closed Sales: 190
- Conversion Rate: 5.42%
- Average Call Duration: 66 Seconds
